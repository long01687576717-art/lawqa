## 一、本轮改动内容

1. **库外知识约束**（llm.py / streamlit_app.py 第 10 条提示词）：问题涉及库外法规时，可以说明法规名称并建议查阅，但**不得输出具体内容（条号、适用要件、天数、比例、金额等）**。
2. **年龄表述换算**（synonyms.py）：用正则识别问题中的数字年龄（"X 岁""X 周岁""未满 X 岁"），换算为法律分类术语——未满 16 周岁 → "未满十六周岁 未成年人 禁止招用"；16–18 周岁 → "未成年工"。

## 六、内存占用口径说明

用户询问的 47.3MB 与 78.5MB 口径澄清（我这边只有 47.3MB 的记录，78.5MB 未在我侧出现）：

| 口径 | 数字 | 方法 |
|---|---|---|
| tracemalloc 核心对象 | **47.3 MB** | 只测线上版核心数据（laws+cases+BM25+引用索引+标注+同义词）的 Python 对象净增，不含解释器/进程 |
| psutil 完整进程 RSS | **147.1 MB** | 含 Python 解释器（34.2MB）+ 数据（47.3MB）+ numpy/其他库 |

无论哪个口径，均**远低于 1GB**，线上版（纯 BM25）在 Streamlit 1GB 云环境可正常运行。78.5MB 我无法确认来源，若为某种中间口径也仍在安全范围。
